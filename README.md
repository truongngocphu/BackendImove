# TH79 iMove Core Backend 1.6.0

Node.js/Express Core API cho iMove. Development port: `5050`; MongoDB database: `th79_imove`.

```powershell
npm install
npm test
npm run check
npm run dev
```

Startup tự chạy database repair schema 1.4.0. Các module chính: service catalog, versioned pricing, promotions, matching/dispatch, notifications 1–4, OSM/OSRM maps, Trust & Safety, Driver experience, analytics và settlement/reconcile.
